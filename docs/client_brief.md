# Weekly complaint review

Maya, a fictional state financial regulator analyst, decides which product and issue to inspect first. Each week she receives the latest completed monthly analysis. The watchlist stays unchanged until a new mature month or a revised snapshot arrives.

Read product, issue, period, count, share within product, expected count, method and evidence together. Severity describes the size of a deviation. Statistical confidence applies only to its specified model. Examine changes in product definitions and publishing patterns before escalating. Compare the current month with neighboring months and inspect the source taxonomy.

Review effectiveness is measured by event-window recall and unmatched alerts per year in the retrospective comparison. Release dates are proxies, several actions can map to the same series, and a published complaint is a selected report. The analyst cannot infer firm-level incidence, wrongdoing, or customer risk from these records. There is no customer-volume denominator.
